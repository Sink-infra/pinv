# LinalgPinv 数值路径与内存协议

本文件可以修改，仅供维护者理解实现依据，放在 `code/` 中随实现维护。

## 算术与接受策略

FP32 的舍入单位为 2⁻²⁴。高低双分量使用 TwoSum 与乘积分裂保存舍入余项，
分裂因子为 2¹²+1；双分量误差预算以 2⁻⁴⁸ 为单位。
标量补偿保留显式中间结果，向量补偿保留操作顺序和流水线依赖。

直接求逆的两个门槛属于不同策略：

- 0.81 = 0.9²：保守的全秩逆接受门槛。
- 81 = 9²：使用谱间隔承诺的全秩分类门槛。若存在不超过截断阈值十分之一的
  非零奇异值，则逆矩阵的谱范数乘以阈值至少为 10，Frobenius 范数也至少如此。
  小于 9 的上界因此排除这一情况；9 留有边界裕量。

3.6e9 与 4.0e11 是快速求逆、残差修正之间的经验选路界，
不能代替残差与逐元素误差检查。2¹²+1、舍入单位、接受门槛和缩放上限
均由 pinv_contract.h 提供；修改数值策略时须同时核对其适用条件。

## 矩形直接分解

令 B 为高矩阵：高输入取 B=A，宽输入取 B=Aᵀ。
以二的整数次幂 p 归一化 B，每个工作行同时保存一个 B 列和一个 V 列。
Jacobi 旋转作用于这两个部分，得到 C≈BV。最终使用
Vᵣ diag(σᵣ⁻²) Cᵣᵀ 构造高矩阵的伪逆，宽输入将结果转置。

点积采用补偿乘积和 TwoSum 树形归约。后验测量的点积和矩阵残差使用三分量累加，
以 2⁻⁷² 计累加余项；两分量范数与输出重建另计 2⁻⁴⁸ 舍入预算。旋转、范数与重建共享补偿原语。
初始阶段至多 40 轮；未通过后验检查时从原始输入重新进行双分量旋转，
稳健阶段至多 120 轮。轮数上限本身不是成功条件。

## 后验检查

令 Uᵣ=Cᵣ diag(σᵣ⁻¹)，检查：

- C−BV 的 Frobenius 残差；
- BᵀUᵣ−VᵣΣᵣ 的 Frobenius 残差；
- VᵀV−I 和 UᵣᵀUᵣ−I 的 Frobenius 范数；
- 舍弃列 Gram 矩阵的绝对行和上界。

点积的树形归约深度、范数归一化和矩阵乘积的顺序累加分别计算运算预算，
按对应精度分别采用 γ(q)=q·u/(1−q·u)，并保留正向裕量。
矩阵乘积预算随内积长度增长，树形归约预算随归约深度增长。

当正交性缺陷 η<1 时，极分解正交化的距离上界为
η/(1+sqrt(1−η))。用此界修正上述两个分解残差，
构造具有保留子空间与补空间的块对角矩阵 B₀，并得到 ||B−B₀||F≤δ。
B 的范数由 C、分解残差和 V 的最小奇异值下界共同约束。

保留奇异值下界记作 s，舍弃块的奇异值上界记作 d。
通过 Weyl 界同时检查：

- 保留部分严格高于截断阈值的上界；
- 舍弃部分不高于截断阈值的下界；
- 相对阈值使用最大奇异值的区间，而不是单一估计值。

满列秩时不存在右侧舍弃块，不对不存在的块附加舍弃条件。

对称嵌入 H(B) 的非零特征值为 ±σ。截断倒数函数在保留区间与舍弃区间之间的
差商上界为 L=1/[s(s−d)]，因此对应的伪逆误差满足 Frobenius 界 Lδ。
再加入正交化、重建算术与 FP32 转换预算，得到输出误差上界 e。

对每个输出值 x，要求
e ≤ (1e-4+1e-4·|x|)/(1+1e-4)。
由三角不等式，该条件足以推出使用真实参考值幅度的逐元素预算。
未通过检查的结果不作为已认证结果返回，系统测试将识别非有限输出。

## Workspace 协议

pinv_contract.h 同时供 Host 和 Device 使用。metadata 的索引单位是 FP32 元素：

| 区域 | 起点 |
| --- | ---: |
| 核间统计 | 0 |
| 旧主元索引 | 256 |
| Jacobi 列范数 | 512 |
| 分组标记 | 1024 |
| prepared 参数 | 1032 |
| 分组状态 | 2048 |
| 双生产者交换区 | 3072 |

每个 batch 的 metadata 容量为 8192 个元素。不同算法阶段允许复用区域，
阶段转换必须完成对应核间同步。双生产者交换区的实际长度受 Host 容量条件约束。

Cube 区域起点位于矩阵工作区与全部 metadata 之后，按 128 个 FP32 元素对齐。
Cube 控制区占 512 个 FP32 元素；数据区包括两组 5·n² 个 INT8 元素，
以及 25·n² 个 INT32 元素，总计 110·n² 字节。
Host 与 Device 均使用同一个地址与容量公式。

矩形工作区仅保存高低双分量的增广列，容量与轴填充由共享函数计算，
不增加方阵路径的 workspace。

基础 tiling 是扩展 Cube tiling 的首个显式成员。
标准布局、首成员偏移和基础包大小由编译期断言约束。
Vector 逻辑核数和 Cube 物理核数使用各自入口，不依赖宏重命名。
